# Geomat Asistan 📐📱

React Native ve Expo kullanılarak geliştirilmiş, Google Gemini API entegrasyonuna sahip akıllı bir matematik ve geometri asistanı mobil uygulamasıdır.

## Özellikler

* **Kamera ile Soru Çözümü:** Çekilen veya yüklenen matematik/geometri sorularını yapay zeka ile analiz eder.
* **Adım Adım Açıklama:** Sonucu vermekle kalmaz, çözüm yolunu detaylı Türkçe açıklamalarla sunar.
* **Gemini Destekli:** Google'ın güçlü Gemini modeliyle yüksek doğruluk oranına sahiptir.
